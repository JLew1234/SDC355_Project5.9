## Overview This portfolio website is designed and developed to showcase professional web development projects, technical skills, and interactive JavaScript capabilities built throughout the software development curriculum. ## Languages & Technologies Used * 
**HTML5**: Structured semantic layout and markup elements. * 
**CSS3**: Custom styling, responsive flexbox/grid layouts, and theme switching. * **JavaScript (ES6+)**: Dynamic DOM manipulation, object arrays, and persistent session/local storage management. * 
**Git & GitHub / GitHub Pages**: Version control and public web hosting. ## Dependencies & Setup Instructions * 
**Dependencies**: No external frameworks or package managers (like npm or React) are required. Built with vanilla web standards. * 
**Local Execution**: 1. Clone or download the repository to your local machine. 2. Open the project folder in 
**Visual Studio Code**. 3. Use the **Live Server** extension to launch `index.html` in your web browser.
